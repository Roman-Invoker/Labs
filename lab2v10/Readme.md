Під час виконання лабораторної роботи №2 було практично опановано концепції об’єктно-орієнтованого програмування на мові C#, пов’язані з життєвим циклом об’єктів та конструкторами.
Перевантаження та ланцюговий виклик конструкторів: Реалізовано декілька конструкторів для класу, що забезпечує гнучкість при створенні об'єктів. За допомогою синтаксису : this() було налаштовано ланцюговий виклик, що дозволило уникнути дублювання коду ініціалізації та зосередити логіку присвоєння значень в одному місці.  Валідація даних: Забезпечено захист даних об'єкта через приватні поля та інкапсульовані властивості з перевіркою коректності вхідних значень.  Життєвий цикл об'єкта та деструктор: Досліджено три етапи життєвого циклу об’єкта (створення оператором new, використання в програмі та вилучення з пам’яті). За допомогою виклику фіналізатора та примусової збірки сміття, наочно продемонстровано момент знищення об'єктів збирачем сміття
