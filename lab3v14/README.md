У всіх трьох сценаріях ресурс зрештою звільняється, але по-різному. using — найнадійніший спосіб: Dispose() гарантовано викликається одразу після виходу з блоку, навіть якщо всередині сталася виняткова ситуація. Явний виклик Dispose() дає той самий результат, але залежить від уважності програміста: за наявності return або винятку до цього рядка ресурс залишиться захопленим. Без Dispose() з'єднання закривається лише тоді, коли до об'єкта дійде GC і запустить деструктор — момент недетермінований, і без GC.Collect() це могло б статися за секунди чи хвилини. Тому деструктор — це резервний механізм, а не основний спосіб керування ресурсами.
