У межах лабораторної роботи реалізовано клас Book, який містить:

Приватні поля:

private string title — назва книги.

private string author — автор книги.

Публічну властивість:

public int Year { get; set; } — рік видання книги.

Конструктор:

Book(string title, string author, int year) — ініціалізує початковий стан об'єкта.

Деструктор (фіналізатор):

~Book() — демонструє знищення об'єкта збирачем сміття.

Метод:

GetInfo() — повертає відформатований рядок із повними даними про книгу.
